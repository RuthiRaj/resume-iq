# ResumeIQ AI Evaluation Framework

> **Status:** Phase 2.2 Golden Benchmark Dataset Complete

---

## 1. Purpose of the Evaluation Framework

The **ResumeIQ AI Evaluation Framework** provides an offline test harness and contract specification to measure the quality, accuracy, grounding, claim preservation, score stability, and efficiency of the ResumeIQ AI pipeline.

It allows evaluation sweeps to run offline against established golden benchmark datasets without changing production code or mutating application database states.

---

## 2. Distinction: Production Schemas vs. Evaluation Schemas

- **Production Schemas (`app/schemas/`):** Define the live HTTP request/response payloads, Firestore database records, and AI provider interfaces consumed by the Next.js frontend and FastAPI backend (`AnalyzeRequest`, `AnalyzeResponse`, `CandidateEvidence`).
- **Evaluation Schemas (`evaluation/schemas/`):** Define contracts for benchmark cases (`EvalCase`), expert annotations (`GroundTruthRequirement`), evaluation run tracking (`EvaluationMetadata`), prediction wrappers (`EvaluationPrediction`), individual metric outcomes (`MetricResult`), and aggregate benchmark reports (`EvalReport`).

Evaluation schemas **compose and reference** production models (`CandidateEvidence`, `RequirementMatch`, `ScoreBreakdown`) directly, guaranteeing 100% compatibility with production data structures.

---

## 3. Distinction: Ground Truth vs. Model Predictions

- **Ground Truth (`GroundTruthRequirement`):** Represents authoritative, human-annotated gold standard expectations. Ground truth is **reference input**, NOT model output.
- **Model Predictions (`EvaluationPrediction`):** Represents the actual output generated by the live ResumeIQ AI engine when processing a benchmark case input.

The evaluation runner compares `EvaluationPrediction` against `GroundTruthRequirement` using deterministic metric algorithms. Ground truth is never overwritten or mutated by predictions.

---

## 4. Golden Benchmark Dataset (`evaluation/dataset/`)

Phase 2.2 establishes 15 expert-annotated benchmark cases with 60 requirement-level ground truth expectations (`evaluation.dataset.golden_cases`).

### Ground Truth Methodology Principles
1. **Expert Annotation:** Expectations reflect human domain expert evaluation, isolated from model output bias.
2. **Deterministic Evidence Anchoring:** Acceptable evidence lists exact verbatim phrases from the candidate resume.
3. **No ATS Bounds Contamination:** `expected_min_ats_score` and `expected_max_ats_score` are `None` across all cases to prevent arbitrary score range pollution prior to evaluation metrics design.
4. **Zero Production Mutation:** Production code (`backend/app/`) remains completely unmodified.

## 5. Architectural Principle: Not Production AI Logic

> [!IMPORTANT]
> The evaluation framework operates **entirely outside the live production AI decision path**.

```
Golden Case (evaluation/dataset/golden_cases.py)
  ↓
Evaluation Runner (offline test harness)
  ↓
ResumeIQ AI Pipeline (app/ai/orchestrator.py)
  ↓
Evaluation Prediction (EvaluationPrediction)
  ↓
Evaluation Metrics & Benchmark Report (EvalReport)
```

The evaluator **observes and measures** system quality; it never alters production prompts, scoring math ($40\%/30\%/15\%/15\%$), or matching rules.
